Undergraduate dissertation

State-Dependent Graph Portfolio Optimization using Selective State Space Models and Regime-Adaptive Graph Learning

Advisor: MSc. Ngo Phu Thanh

This project studies regime-dependent financial networks and their use in portfolio construction. It combines selective state-space models with regime-adaptive graph learning to represent changing cross-asset dependencies and support portfolio decisions during volatility and regime transitions.
